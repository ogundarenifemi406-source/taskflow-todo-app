# TaskFlow

A simple and responsive to-do list web application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Track remaining tasks
- Add tasks using the Enter key
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## What I Learned

This project helped me practice DOM manipulation, event listeners, functions, conditional logic, dynamic HTML elements, and basic responsive styling.
